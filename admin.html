⚙️ Konfigurasi Admin Panel

Ambil dari Firebase Console → Realtime Database. Harus sama dengan URL yang dipakai para guru.
Struktur default: instrumen/teachers/<id>
Jika diisi, akan diminta setiap kali membuka halaman ini.
Cara guru mengirim data:
1. Buka aplikasi guru → klik ☁️ Sync → tab 🔥 Firebase
2. Paste URL Firebase → Simpan → Kirim ke Firebase
3. Ulangi setiap kali ada update nilai
4. Setelah semua guru mengirim, halaman ini akan menampilkan datanya otomatis.
