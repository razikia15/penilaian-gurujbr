🔥 Sinkronisasi Firebase Realtime Database

URL sudah otomatis terisi. Cukup klik ☁️ Kirim ke Firebase untuk sync.
📋 Cara Pakai (Mode Personal):
1. Pastikan data sudah diisi dengan benar
2. Klik ☁️ Kirim ke Firebase untuk backup pribadi ke cloud
3. Klik 📥 Muat dari Firebase untuk ambil data Anda dari device manapun
4. Data tersimpan per akun guru — guru lain tidak melihat data Anda
🔒 Keamanan: Test mode = siapa pun yang punya URL bisa akses. Untuk produksi, ubah Rules jadi "auth != null" dan aktifkan Firebase Authentication.
